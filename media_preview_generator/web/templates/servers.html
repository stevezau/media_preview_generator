Worked example + when you'd need this

Suppose your server stores a file at /data_16tb/movies/Inception.mkv but this app's container mounts that disk as /mnt/plex/movies/Inception.mkv — the server tells this app "the file is at /data_16tb/...", but this app can't open that path because it doesn't exist inside the container. Add a row:

  • Path on media server: /data_16tb/movies
  • Local path on this app: /mnt/plex/movies

Path on Apps (third column) is for when you trigger generation from Sonarr / Radarr / Tdarr webhooks and those apps see your media at a different path than your media server reports — e.g. Sonarr sends /tv/Show/S01E01.mkv but Plex reports /mnt/Media/TV/Show/S01E01.mkv. Enter that app's path root here so we can map it to your local mount. Leave blank if your webhooks already send the same paths the server uses (e.g. Plex/Emby/Jellyfin library.new webhooks, which resolve the path through the server).

    Send intro & credits markers to Plex?

    Plex has no way for apps to add intro or credits markers, so they are written straight into Plex's database — the same place Plex stores its own.

    • Tested on Plex 1.43. A future Plex update could change this; we stop writing if the database looks different.
    • The app must run on the same machine as Plex.
      Map Plex's config folder into both containers from the identical host path (on unRAID, don't mix /mnt/user and /mnt/cache).
    • If Plex re-detects an item itself, it can replace ours. The next job that checks the file puts them back, unless you choose to keep Plex's.
    • Viewers need Plex Pass (or Plex Home) to see skip buttons.
