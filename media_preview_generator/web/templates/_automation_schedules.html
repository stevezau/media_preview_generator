Overview

Schedules run jobs on a timer so you don't have to start them by hand. Tick any of Previews, Intro & Credits and Plex loudness, then choose which files:

  • Whole library — check every file in the chosen libraries and do whatever is missing. Good for weekly or nightly runs.
  • Recently added — a fast poll that only looks at what was added in the last few minutes or hours. Good for tight, frequent intervals (every 15 min) so fresh imports are handled quickly. If your downloader (Sonarr/Radarr/Tdarr) can fire a webhook on import, the Triggers tab is even faster — it fires the moment new media lands.
You can have as many schedules as you like.
Jobs request work; worker groups provide capacity.

Jobs wait while their groups are outside available hours. A global pause skips scheduled runs. A schedule's optional Stop pauses its own current work.
