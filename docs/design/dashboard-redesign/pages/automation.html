Overview

Webhooks generate previews automatically when new media lands in Plex, Emby, or Jellyfin. Pick the source that matches how your media gets in.

How do you add media?
Sonarr / Radarr / Sportarr grab your media
Sportarr is the Sonarr fork for sports. Works for any server.
Use the *arr webhook
Tdarr, FileFlows, or a script transcodes files
Works for any server.
Use the Custom webhook
You add media manually to Plex
Plex only: it is the only vendor with a server-side webhook we can subscribe to.
Servers → Plex → Webhook
You add media manually to Emby
Emby has built-in webhooks that post to the same /incoming URL.
Setup steps
Dashboard → Webhooks → Add Webhook, URL https://<your-host>/api/webhooks/incoming?token=<webhook secret>, tick Library → New Media Added.
Open Emby setup
You add media manually to Jellyfin
Install the official Webhook plugin; same /incoming URL as Plex and Emby.
Setup steps
Dashboard → Plugins → Catalog → Webhook. Add a Generic destination with URL https://<your-host>/api/webhooks/incoming?token=<webhook secret>, subscribe to Item Added.
Open Jellyfin setup
Server webhooks miss file upgrades

Plex, Emby and Jellyfin only fire for brand-new library items. For replaced files use the Sonarr/Radarr "On Upgrade" event.

Why this happens
When Sonarr or Radarr upgrades an existing file in place, the media server keeps the same library item, so the new file is never seen as "added" and the server-side webhooks do not fire. The "On Upgrade" event works regardless of which media server you use.

*arr apps

Per-import trigger

Sonarr, Radarr, and Sportarr POST here as soon as they finish importing or upgrading a file. Copy the URL, add your auth token, done.

Adds ?server_id=<id>. Use when the same library exists on more than one server and you want one specific target.

Sonarr webhook URL
http://127.0.0.1:18080/api/webhooks/sonarr
Replace 127.0.0.1:18080 with your server's address.
Setup in Sonarr
  1. Go to Settings → Connect → + → Webhook
  2. Set Name: Plex Previews
  3. Set URL: copy the URL above
  4. Under Events, enable On File Import and On File Upgrade
  5. Authentication: put your webhook secret in Password (leave Username blank), or add header X-Auth-Token = your secret
  6. Click Test, then Save
Radarr webhook URL
http://127.0.0.1:18080/api/webhooks/radarr
Replace 127.0.0.1:18080 with your server's address.
Setup in Radarr
  1. Go to Settings → Connect → + → Webhook
  2. Set Name: Plex Previews
  3. Set URL: copy the URL above
  4. Under Events, enable On File Import and On File Upgrade
  5. Authentication: put your webhook secret in Password (leave Username blank), or add header X-Auth-Token = your secret

Custom webhook

Any HTTP client

Trigger previews from any tool that can send an HTTP POST: Tdarr, FileFlows, shell scripts. Send a file path and it runs through the same pipeline as Sonarr/Radarr.

Custom webhook URL
http://127.0.0.1:18080/api/webhooks/custom

To pin to one server use the "Publish to which server?" picker in *arr apps; it appends ?server_id=<id>. Send {"eventType": "Test"} to verify connectivity.

Payload: single file
{
  "file_path": "/media/movies/Movie (2024)/Movie.mkv"
}
Payload: multiple files
{
  "file_paths": ["/media/tv/Show/S01E01.mkv", "/media/tv/Show/S01E02.mkv"],
  "title": "Optional display label"
}
Tdarr setup
Add a flow plugin or post-process hook that POSTs the output file path to the URL above.
FileFlows setup
Add a Web Request node: POST, JSON body with file_path.
curl example
curl -X POST -H "X-Auth-Token: <secret>" \
  -H "Content-Type: application/json" \
  -d '{"file_path": "/media/movies/Movie.mkv"}' \
  http://127.0.0.1:18080/api/webhooks/custom
