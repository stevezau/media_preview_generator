Why these starting times. They have to be somewhere near the truth so the drag is short, and obviously chosen so nobody reads them as an answer. A whole 30 seconds from 0:00, or a whole minute ending exactly at the end of the file, is a shape the audio and text detectors practically never produce — every real answer they have written has odd seconds in it. (A file whose chapter marks happen to be round is the one way the same shape can turn up honestly.) On a file of ordinary episode or film length these sit inside the usual bounds, so the editor opens with no warning already showing. Nothing is guessed from the season, the neighbours or the sources. The credits and preview starts are clamped at 0:00, so a file shorter than the seed itself still gets a legal marker — under four minutes for credits, under two for a preview, the editor then shows its ordinary “That's earlier than credits usually start. This will still be saved.” warning, which is true either way.
